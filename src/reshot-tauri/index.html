Global hotkeys:

Click a field, then press a key combination. Print Screen (PrtScn / Prnt) is supported.

Radial menu:

Holding the capture hotkey opens the quick menu. Normally the wheel stays up after you let go and waits for a left click; the centre, or anywhere outside the wheel, cancels. With this on the menu lives only while the key is held: point at a slice and release to run it, and a flick past the rim counts as pointing that way.

System:

Needed only to capture over applications that run as administrator. Windows asks for permission once, when this window closes; after that it starts elevated silently, through a scheduled task named “Reshot”.

About:

Reshot is a resident screenshot and screen-recording tool for Windows. It sits in the tray on a global hotkey and does no work at all until you call it.

Pressing the hotkey freezes every monitor at once. Select an area of any shape: rectangle, ellipse, triangle, lasso or polygon. Annotate it with brushes, shapes, text, blur and pixelation, then copy it, save it, or record it as video. Anything outside a non-rectangular selection is exported as transparency.

Video is written as H.264 / MP4. System audio and the microphone are captured separately, so you can pick which tracks to keep after the recording ends. Right-click the record tool to record only certain windows' sound. There is also a standalone audio recorder that can capture individual windows.
